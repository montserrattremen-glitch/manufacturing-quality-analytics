# Manufacturing Quality & Production Analytics
Power BI dashboard analyzing manufacturing production, quality and operational efficiency. 

### Project Overview
This project uses Power BI to analyze manufacturing production, product quality, and operational efficiency. The goal es to transform production data into interactive visualizations that help identify quality issues and monitor operational performance. 

### Business Questions
- How many units were produced, and how many were defective?
- What is the overall defect rate?
- Which products and shifts have the highest number of defective units?
- How does production compare with capacity across production lines?
- How do downtime and production costs vary by line?

### Tools & Skills
- **Power BI:** Interactive dashboards and data visualization
- **Power Query:** Data preparation and transformation
- **DAX:** KPI calculations and measures
- **Data Quality:** Duplicate and missing-value review
- **Business Analysis:** Manufacturing quality and operational performance

### Dashboard Pages
**1. Production:** Production KPIs, defect rate, availability, and production trends over time.

**2. Quality:** Defective units by product and shift, with a production-line filter.

**3. Operational:** Production versus capacity, downtime, and production costs by line.

### Data Preparation
The dataset was reviewed for duplicate records and missing values. Three duplicate rows were removed, and four missing values were identified in the downtime_minutes column. The missing values were retained for review rather than automatically replaced with zero.

### Key Findings
Key findings and recommendations will be added after reviewing the dashboard results and validating the measures.

### Project Purpose
This project demonstrates practical skills in data visualization, KPI development, data quality review, and manufacturing performance analysis.

Notes

This project uses a sample manufacturing dataset for learning and portfolio purposes. The results do not represent the performance of an actual company.
